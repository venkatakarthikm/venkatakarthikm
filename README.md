An API scheduler and code-execution platform for developers who need HTTP calls or scripts run on autopilot no server babysitting required.

A real-time cricket tracking platform, built because free live-score APIs don't really exist so it aggregates data through custom scrapers instead.

Live scores, standings, and ICC rankings update with zero flicker, using React state management tuned for high-frequency changes. Push notifications via OneSignal, plus SEO and Analytics work on the growth side.

<br>`React` `REST API` `Web Scraping` `OneSignal`

<br>`MERN Stack` `Payment Gateway` `Role-Based Auth`
